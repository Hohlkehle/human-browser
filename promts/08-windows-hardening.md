# Этап 8: Windows deployment и hardening

Цель: подготовить сервис к постоянной работе.

Добавь отдельного Windows-пользователя с минимальными правами, установку
gateway и MCP как служб, автозапуск, секреты в Windows Credential Manager или
защищённом environment store, ротацию bearer token, структурированные логи с
redaction, ограничение размера/срока хранения, emergency stop, firewall rule
только для локальной подсети и проверку недоступности 9229 через публичный
интерфейс.

Документируй обновление, откат и удаление. Автоматизируй security checklist.
Проверь восстановление после перезагрузки и фактическую остановку доступа.
