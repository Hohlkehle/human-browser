# Этап 9: end-to-end Partslink24

Цель: проверить реальный сценарий без передачи пароля ИИ.

Сценарий:

1. MCP открывает `www.partslink24.com`.
2. При необходимости входа возвращает `HUMAN_REQUIRED`.
3. Пользователь вручную входит в Chrome.
4. `human_resume` подтверждает готовность.
5. MCP ищет автомобиль.
6. При CAPTCHA снова возвращает `HUMAN_REQUIRED`.
7. Пользователь решает CAPTCHA.
8. MCP продолжает ту же сессию.
9. MCP извлекает только запрошенные каталожные номера и применимость.

Не логируй VIN полностью: маскируй средние символы. Не читай password-поля,
cookies или токены. Не подтверждай покупку/заказ. Добавь mock-сценарий CI без
обращения к Partslink24 и отдельно документируй реальные результаты.

Готовность: полный сценарий без повторного входа, CAPTCHA передаётся человеку,
после ручного действия агент продолжает на той же странице.
